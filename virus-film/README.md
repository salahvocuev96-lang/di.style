# ВИРУС: МИССИЯ ПО ЗАРАЖЕНИЮ

Мультяшный научно-популярный ролик (условная визуализация на примере вируса гриппа A).
Готовое видео: `virus_mission.mp4` — 1920×1080, 60 fps, H.264 (High, yuv420p), AAC 48 кГц стерео, 50.0 с (3000 кадров).

## Файлы
| Файл | Что делает |
|---|---|
| `core.js` | утилиты, перспективная камера, спрайты с размытием (DOF), липидный бислой, персонаж-вирион и его мимика, подписи |
| `scenes12.js` | сцена 1 (микромир, титр) и 2 (капля, слизь и реснички) |
| `scenes34.js` | сцена 3 (рецептор → эндоцитоз → слияние) и 4 (ядро, рибосома, сборка) |
| `scenes56.js` | сцена 5 (почкование, иммунный ответ) и 6 (отъезд, финальная фраза) |
| `main.js` | монтаж, переходы, motion blur накоплением субкадров |
| `index.html` | превью в браузере (`index.html?t=12.5` — конкретный кадр) |
| `audio.py` | музыка и звуковые эффекты (синтез на numpy) → `audio.wav` |
| `dump_events.js` | выгружает таймкоды событий анимации в `events.json` для синхронизации звука |
| `render.js`, `build.sh` | покадровый рендер в Chromium (Playwright) и сборка MP4 через FFmpeg |
| `STORYBOARD.md` | раскадровка и выбранные варианты сцен |

## Повторный рендер
Нужны Node.js с `playwright` (Chromium), Python 3 с `numpy`, `ffmpeg`.

```bash
./build.sh            # финал: 2 субкадра на кадр (motion blur), ~6–7 мин на 4 ядрах
./build.sh 1 test.mp4 # быстрый черновик без субкадрового смаза
```
