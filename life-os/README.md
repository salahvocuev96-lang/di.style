# My Life OS

Личное PWA-приложение: привычки, расписание, проекты, спорт, английский, сон.
Полностью изолировано в папке `life-os/` и не затрагивает сайт di.style.

## Запуск

    cd life-os
    npm install
    npm run dev       # разработка
    npm test          # тесты логики и хранилища
    npm run build     # сборка в life-os/dist

## Устройство

- `src/data/` — слой данных. Локальная база IndexedDB (Dexie). Любая запись идёт
  через `repo.ts`: поля `updatedAt`, `syncedAt`, `deletedAt` уже готовят данные
  к синхронизации с Supabase (V2) без переписывания интерфейса.
- `src/lib/logic.ts` — расписание дня, свободные окна, регулярность привычек,
  адаптация дня под энергию, достижения, статистика сна.
- `src/pages/` — экраны. Роутинг через `#/адрес`, поэтому приложение работает
  из любой папки любого статического хостинга.

## Данные

Хранятся в браузере устройства. Резервная копия: Настройки → «Скачать копию (JSON)».
Восстановление: «Восстановить из файла» (объединение или полная замена).
